Entry for the make.fun bounty **One-Line Robot Wedding Vows**
(https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

`main.py` writes one funny single line of wedding vows for a robot couple
to `/output/entry.txt` — 136 characters, one line, a promise with a
machine-specific payoff in the last words.

Run it with:

```sh
python3 main.py
```
